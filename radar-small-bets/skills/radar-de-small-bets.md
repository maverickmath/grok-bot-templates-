# Radar de small bets

## Goal
Build and refresh a **queue of small experiments** someone can run this week. Each bet must be cheap, fast, abandonable, and buy money, information, or a new option. This is **not** a hunt for asymmetric gigs or open bounties — those belong to the asymmetric-opportunities radar.

## Hard filters (all required)
Keep only experiments that pass every bar:
- **Custo**: nearly free (time + tiny tools; no meaningful cash outlay)
- **Tempo**: runnable in under a few hours (prefer ≤60–90 min for a first try)
- **Upside**: plausible path to money, useful information, or a new option
- **Abandonável**: easy to stop with almost no sunk cost or reputation lock-in

Drop anything that needs a big project, a long commitment before first signal, or hard-to-reverse spend.

## What a good small bet looks like
Prefer bets that:
- Contact real demand (messages, posts, offers, landing pages, waitlists)
- Produce a clear yes/no or number within one session
- Can be repeated or scaled only *after* a positive signal
- Fit the person's known skills, language, timezone, and constraints

## Process each run
1. Start from the person's context (role, interests, recent asks, constraints). If unknown, keep bets generic but still executable.
2. Generate or refresh 5–10 candidate experiments.
3. Filter with the hard bars above; discard weak or vague ones.
4. Score lightly for **signal speed** (how fast you learn) and **optionality** (doors it opens), not for max payday.
5. Deduplicate against bets already in the recent queue.
6. Deliver a short queue in the person's language. Lead with the top 3 to run next; keep the rest as backlog.

## Card format (required fields)
For each bet:

```
Experimento: …
Custo: … (tempo; dinheiro se houver)
Upside: …
Downside: …
Informação obtida: …
Próximo passo concreto: … (uma ação, ≤90 min)
```

Optional: tag `dinheiro` | `informação` | `opção` for the primary upside.

## Rules
- Never invent live payouts, open program status, or external deadlines as if verified. Upside is a **hypothesis**, labeled as such when speculative.
- Prefer concrete next steps ("enviar 10 DMs", "publicar 1 post com CTA", "ligar landing + 5 convites") over vague advice.
- If nothing passes the filters, say so in one sentence — do not pad.
- Keep the queue short; a backlog of 5–10 is enough.
