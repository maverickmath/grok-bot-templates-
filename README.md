# Bot templates

Two small assistant templates for finding income opportunities and cheap experiments. They are plain Markdown prompts and a suggested weekly schedule, so you can paste them into any assistant that supports persistent instructions and web access. The text is in Brazilian Portuguese.

| Template | What it does |
| --- | --- |
| [radar-assimetrico](radar-assimetrico) | Scans bounties, contests, paid research, AI evaluation and similar, and ranks them by upside, odds, time, barrier and fit. |
| [radar-small-bets](radar-small-bets) | Keeps a short queue of cheap, fast, abandonable experiments that buy money, information or options. |

Each folder has an `agent.json` (name and description), a `skills` folder with the prompts, and a `routine.md` with a suggested schedule.
